# How LLMs were used in this project

Two issues plagued my mind when I started this project:
- How can I use LLMs to amplify productivity
- How I can increase my contextual memory when context switching between work and personal life
    - I struggle with a very short term memory and often forget the big picture. This has caused me to not be able to understand why I am pursuing a certain project and has often allowed me to leave projects prematurely without finishing because I do not find enough joy (since in my mind I have not achieved anything)

I used LLMs in Plan mode to tackle both these issues. Plan mode helped me form a conversational journey to my project. It would help me form short but concrete milestones (achieveing them would provide enough dopamine to continue the project).
Regardless of whether I would end up using an decision made by the LLM I would often come back to certain decisions to question them and change them if needed. The conversational history allowed me to go back and maintain architecture decision records with the ability to converse about these decisions at any time.
