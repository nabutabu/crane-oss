# How LLMs were used in this project

Two questions plagued my mind when I started this project:
- How to use LLMs to amplify my productivity
- How to increase my contextual memory when context switching between work and personal life
    - I am often unable to focus on one task for too long which is likely a by product of using too much of the "smart phone". It's often led me to not be able to keep track of the big picture and the purpose behind starting a project. As Software Engineers do, I would often leave my projects unfinished, in a state where they won't even be qualified as projects sometimes. I noticed that this was also a by product of not achieving certain goals I made for myself (because I made bad extremely big goals and set myself up for failure), which would make unhappy and demotivated to work on the project. Short goals with LLMs fixed my dopamine issues.

I used LLMs in Plan mode to tackle both these issues. Plan mode helped me form a conversational journey to my project. It would help me form short but concrete milestones (achieveing which would provide enough dopamine to continue the project).
Regardless of whether I would end up using a decision made by an LLM I would often come back to certain decisions to question them and change them if needed. The conversational history allowed me to go back and maintain architecture decision records with the ability to converse about these decisions at any time.
